A program that writes one dad joke to `/output/entry.txt`, for the make.fun competition [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

## Run it

```sh
python3 main.py
```

It writes the dad joke below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The dad joke is 76 characters, inside the 1 to 200 gate.

> I asked the calendar for a day off. It said sorry, all my days are numbered.
